## About

This Task Management System is a simple web application used to manage and display information about tasks. It allows users to add new tasks, search for tasks, mark tasks as completed, and navigate between different sections. The project uses HTML, CSS, JavaScript, Bootstrap, GitHub Actions, and Jenkins for development and CI.
## Tech stack

- Frontend: HTML, CSS, JavaScript,Bootstrap
- Backend: None
- Database: None
